# 船舶待同步佇列修正（2026-11-10）

截圖顯示待同步 18 筆；這是本機佇列批數，不能據此判定正式雲端的具體失敗原因。本次未取得該瀏覽器的正式佇列或雲端執行記錄。

已修正可由程式與隔離測試重現的缺陷：

- 前置讀取逾時不再標記為「寫入結果不明」，避免未送出批次被永久阻擋自動補傳。
- 寫入逾時時保留實際送出快照，背景重試先核對該快照；完全吻合才移除，不盲目重送。
- 未明確收到 ok:true 不移除佇列。
- 前置合併及讀回驗證都以作業編號加碼頭識別船舶，避免同編號跨碼頭混寫或錯誤判定重複。
- 背景同步顯示實際處理階段；失敗顯示同步暫停原因與保留批數，不再僅顯示待同步。
- 切換月份立即依選取月份重新繪製，再讀取雲端；讀取失敗仍保留正確月份範圍。
