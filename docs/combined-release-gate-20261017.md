## 合併範圍

1. 管理同步離頁取消讀取、舊頁回應失效、晚到 ACK 不再通知、返回頁面保留通知重新讀取。
2. 管理快取工作集最多 12 份、8 MiB 序列化 payload 估算；IndexedDB 歷史快照保留，待傳寫入不受影響。
3. 管理快取清單只查目前使用者七個 system key，不以 getAll 取回全部歷史快照。
4. 效率隔離頁的 SSO 驗證對 GAS 的特定「雲端正在同步管理員資料，請稍後重試 SSO 驗證」回應保持為驗證未完成，不再誤標為登入失效。這個回應仍丟出錯誤；沒有自行授予權限、建立 Session、回報登入成功或清除真正的權限拒絕。

上述新功能目前只在隔離測試模式啟用，正式打卡流程及核心未修改。Pulse 本身未修改。候選頁顯示驗收版 20261017.1 可辨識新資產，但尚未部署，不可把現有線上隔離頁算作新候選的瀏覽器驗收。
