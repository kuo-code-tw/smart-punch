# 共用歷史中文船名對照

來源：交通部航港局「國際商港船舶進出港動態資料」
https://data.gov.tw/dataset/99641

以 2025-01 至 2026-09 共 21 份官方 CSV（64,863 列）建立共用目錄，共 5,916 個英文船名鍵，5,860 個可唯一對應；其中萬海 106 艘。56 個具有中文名或 IMO 歧義的鍵，不在無 IMO 時自動套用。來源檔案網址、月份、列數及 SHA-256 見 data-sources/vessel-name-sources.json；更新腳本為 scripts/build-vessel-name-directory.py。

只發布公有的中英文船名及 IMO，不包含航次、移動紀錄或任何 PORT79 私有作業資料。依政府資料開放授權條款第 1 版使用： https://data.gov.tw/license 。

船舶列表、歷史月份顯示、月報匯出及首頁共用目錄，不依賴近期船期或瀏覽器曾否快取。既有已核定中文名優先保留；不批次改寫船舶作業歷史與數量。萬海「輪」字僅移除船種後綴，以沿用既有畫面的簡稱。

測試遍歷全部唯一船名及多個歷史月份，驗證來源數量、歧義與 IMO 防誤配、保留既有名稱及來源不變。此為顯示及匯出補齊，並不代表已逐筆核對正式私人資料庫全部歷史船舶；本次 Google 後端登入狀態已失效，尚未執行正式歷史全庫缺漏盤點。未出現在官方資料或存在身分歧義的船舶維持未提供，不自行翻譯或杜撰。
