# 同編號跨碼頭作業隔離

問題：司機 WR 與船舶 WS 查找只依 WORKING NO，可能把另一碼頭的數量加入核對。例如 WAN HAI 103 / 5260142 的 79R 541 櫃、80L 31 櫃，80L 會錯算 WR 572 / WS 31。

修正：主檔整理、主檔／明細合併、完工月份及人工修正快取加入碼頭識別；核對、明細視窗、司機船舶選擇及月報匯出帶入所選作業的碼頭。不同碼頭的子作業不得吸收到父作業核對，相同人員／時間在不同碼頭也不可去重。缺碼頭且存在多個可選作業的明細列為待核對，不自動指定。

不改寫正式歷史紀錄或數量、不自動補造碼頭、不重新配置正式 WORKING NO。已有獨立 CALL 或子序號仍保留。

回歸以 541 / 31 案例驗證各自相符、主檔分筆、人員明細及匯出隔離；另驗證缺碼頭待核、來源不變、人工修正不跨碼頭套用，以及原有跨月與重匯規則。實際正式資料仍需登入後驗收，本次不聲稱已重寫或修復正式資料庫。
