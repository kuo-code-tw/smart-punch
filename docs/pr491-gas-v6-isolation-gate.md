# Port79 PR #491 — 隔離 GAS 第 6 版相容性與來源驗收封鎖

日期：2026-11-22（Asia/Taipei）  
狀態：**BLOCKED — 不可將 GAS V6 的補卡結果當作 PR #491 的實機驗收。不可正式部署、合併 PR #490 / #491 或修改正式資料。**

## 證據與限制

- PR #491 基準回歸 https://github.com/kuo-code-tw/smart-punch/actions/runs/45006957486 及管理同步測試 https://github.com/kuo-code-tw/smart-punch/actions/runs/45006957477 均已通過；兩者是程式與合成資料測試，沒有隔離 GAS 的真實補卡。
- 操作人員回報 GAS 第 6 版的 p79CheckDuplicatePunchGuard_(record) 僅接受一個參數，缺少候選所需的 ss、修復函式和來源標記。PR #491 的候選是針對 V100 形狀的 p79CheckDuplicatePunchGuard_(record, ss)，不可直接套用 V6；這是根據操作人員的來源檢查，尚未透過目前的 GitHub 工具取得 V6 整份程式內容。
- 腳本 scripts/apply-gas-stale-open-checkin.cjs 現在會先檢查 V100 函式簽章／必要修復函式／標記，對單參數 V6 直接拒絕，不產生可供誤部署的候選輸出。tests/punch-gas-v6-compatibility-gate.cjs 以合成 V6 形狀測試這個拒絕行為，非對 V6 真實執行。
- GAS 第 6 版的主資料庫 ID 限制不足以證明隔離。年度考勤、排班、請假和工時可能從各自的試算表或預設值讀寫，必須逐 action 核對。

## 推進方式（兩條路徑）

**優先：在獨立 Apps Script 專案準備 V100 相容候選隔離 GAS**，每一讀／寫 action 都明確路由至測試副本並可回讀驗證。禁止回退正式端點。

如要沿用 V6，先取得其完整程式，逐函式建立 V6 專屬介面適配及回歸測試，證明與修補所需的狀態鎖、員工識別、讀取和寫入同等安全。不得直接套 V100 修補工具，也不能以 V100 CI 通過宣稱 V6 驗收通過。

## 前端與實機驗收門檻

- 最新 PR #490 排班前端的自訂 GAS URL 可能遭內建來源覆蓋；人資頁在部分錯誤情境也會切回內建正式 GAS。隔離驗收前端必須確保端點無效時 fail closed，絕不能回退。
- 獨立瀏覽器 Profile、獨立 GAS 專案與 Web App、獨立登入憑證；阻擋正式 GAS／正式試算表的出站流量；GAS 與測試表都使用 Asia/Taipei。
- 使用虛構員工：原排休 → 只補上班卡顯示「打卡待核」→ 下班卡完成後自動帶入實際班別並顯示「休假日有出勤」。保留法定原排、核准假單和漏卡例外，**不能按新增同步按鈕**。
- 再測超過 24 小時的舊未簽退、同日重複、無簽到即簽退、跨日、跨月、跨年、跨分頁，以及不同公司、單位、組別。所有關聯畫面、工時、休假與 Excel 對帳均需與測試後端一致。
- 需有正式資料測前／測後無任何變更的可稽核證據；沒有證據即不放行。

此文件只是一份驗收門檻，不代表已讀取 GAS V6 全部程式、建立獨立部署或執行真實補卡。
