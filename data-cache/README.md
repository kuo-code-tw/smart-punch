# 79號碼頭雲端資料庫

此 GitHub 目錄只保存快取設定及 schema。員工、人資、考勤、請假、排班、船舶資料不寫入 GitHub。

在七大系統的「功能選單 → 資料快取中心」開啟「79號碼頭雲端資料庫」。

- 電腦 Chrome／Edge：先建立「79號碼頭雲端資料庫」資料夾，再按「選擇電腦資料夾」授權。現有登入帳號的快取會複製到該資料夾，之後讀取的資料自動保存；原有瀏覽器快取仍作為快速讀取層。
- 手機／不支援資料夾的瀏覽器：按「保留手機／瀏覽器資料」。瀏覽器是否同意持久儲存會顯示實際結果，並可將網站加入主畫面；手動清除網站資料仍會刪除快取。
- 初次使用可按「下載目前系統完整資料」或「下載七大系統完整快取」。
- 電腦清除網站資料後，硬碟檔案仍保留；重新登入並重新選擇同一資料夾，即可按原快取鍵讀回。權限失效時按「重新授權資料夾」。
- 「停用資料夾」不刪除硬碟檔案。「清除本機快取」只清除瀏覽器快取，資料夾啟用時仍可讀回；如需刪除硬碟快取，請先停用，再自行刪除資料夾中的 `port79-snapshots-v1`。

資料夾是讀取快取，不是雲端資料來源。修改仍使用各系統既有儲存與上傳流程；不增加通用離線重播，以免重複打卡或覆寫他人排班。雲端儲存／待上傳狀態以各系統為準，網頁關閉時不承諾背景同步。

實作：`assets/port79-data-cache.js`。IndexedDB `port79-system-cache-v1` schema v2 增加 `settings` 儲存已授權資料夾 handle；快取在 `snapshots`。硬碟依完整請求鍵 SHA-256 命名 JSON，讀回時驗證格式、版本、帳號、角色和完整快取鍵；檔案包含業務資料，使用者應選擇自己管理的資料夾。登入權杖不另寫入資料夾設定。

保留原有快取有效期、變更失效與正式排班／考勤直讀規則。資料夾不會跳過雲端核對，也不代表所有月份可離線編輯；實際加速幅度取決於原頁面的資料讀取流程。
