# F/L 指定職稱及加班換算儲存修正

GitHub Pages 只能發布前端。這兩項根因必須一併部署正式 Apps Script；只修改 GitHub 不會修改 GAS。

1. 先從正式專案備份最新 `Code.gs`，不可直接以舊版完整檔覆蓋較新的正式程式。
2. 執行 `node scripts/apply-gas-scope-conversion.cjs LIVE_Code.gs PATCHED_Code.gs`。補丁要求每個來源錨點唯一，遇到不同版本會停止；請先檢查差異再部署。
3. 將產生的程式替換正式 `Code.gs`。`backend/*.gs` 是此補丁的來源片段，不能在專案新增為重複定義的函式檔。
4. 更新既有 Web App 部署的版本，維持部署網址與權限。`deploymentCheck` 版本應為 `2026.10.28.V62-JOB-SCOPE-CONVERSION-READBACK`。
5. 使用隔離資料驗證 F/L、領班與其他既有職稱的儲存、讀回及指定範圍過濾。既有 HR 動作與細項權限仍由原路由驗證，補丁不自行授予任何帳號權限。
6. 驗證雲端設定中「延／代16-20／正常08-16／班後／4小時」的空白換算會與既有前端規則一致保存為 6.02；非此精確規則不推算，明確設定的換算值（含 0）原樣保留。
7. 修改原申報後，檢查同一申報 ID、時數、換算、時段與永久異動紀錄。這個補丁不批次改寫既有申報；舊空值應經原本的正式修改流程補存，以保留稽核紀錄。

前端已加入回覆核對：如果 GAS 仍回傳空白或不同換算值，會保留編輯內容及原 ID，顯示實際差異，不會宣稱儲存成功。畫面上的規則推算值會註明尚未寫入雲端，月統計仍只採正式已保存值。
